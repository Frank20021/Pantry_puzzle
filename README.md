# Pantry Puzzle

A user-friendly website that helps users make recipes from leftover food items, reducing food waste and saving money.

## Features
- Search for recipes based on available ingredients
- Save favorite recipes
- Calculate potential savings
- Track food waste reduction

## Impact
- Reduce food waste by up to 25%
- Save up to $370 per person annually
- Create sustainable cooking habits

## Setup
1. Clone this repository
2. Open `index.html` in your web browser
3. Start exploring recipes with your leftover ingredients!

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage for saving preferences

## Project Structure
- `index.html` - Main webpage
- `styles.css` - Styling and layout
- `script.js` - Interactive features and recipe logic
